# 安全相簿 (Secure Gallery)

離線優先的 Android 相簿應用，具備密碼鎖、隱藏、自訂垃圾桶天數與多項進階功能。

## 功能概覽

### 安全與隱私
- **PIN 碼鎖**：啟動與分享前需輸入 PIN（4–6 位數字）
- **隱藏**：可將單張照片設為隱藏，不在一般相簿中顯示
- **離線運作**：不需網路，資料存於本機

### 垃圾桶
- **自訂保留天數**：在「設定」中設定垃圾桶保留天數（例如 30 天），到期後自動清除
- **還原 / 永久刪除**：垃圾桶內可還原或永久刪除

### 檢視與分類
- **底部四個分頁**：
  - **相機**：僅顯示手機相機拍攝的照片（DCIM 等）
  - **全部照片**：所有圖片
  - **分類**：依裝置資料夾分組瀏覽
  - **垃圾桶**：已刪除項目
- **排序**（右上角）：類型、大小、拍攝日期、新增日期、修改日期、評等

### 資料夾與封面
- **自訂資料夾封面**：可為資料夾指定封面圖或模糊封面（資料庫與 UI 已預留，完整選圖流程可再擴充）
- **模糊封面**：支援以模糊圖作為資料夾封面

### 圖片操作
- **編輯 / 調色**：類 Lightroom 的調整（亮度、對比、曝光、亮部、陰影、色溫、飽和度、清晰度等）
- **LUX 預設**：可將調色參數存成 LUX 預設並套用
- **分享需 PIN**：分享前必須輸入正確 PIN 才能分享
- **查看圖片資料**：檔名、路徑、大小、尺寸、日期、MIME、資料夾等
- **軟體內移動 / 複製**：可選擇目標資料夾（流程預留，可接實作）
- **重新命名**：重新命名圖片（流程預留）
- **隱藏指定大小以下**：在設定中設定「隱藏小於 X KB 的圖片」，小於該大小的圖片不會在列表中顯示

### 動態圖與進階（預留）
- **動態圖**：可透過 Coil GIF 等載入動圖；從動圖選取重要幀並另存為靜態圖的流程可於後續實作
- **Windows 評等與標籤**：可擴充讀寫 XMP / 檔案中繼資料以相容 Windows 評等與標籤

## 設定
- **垃圾桶保留天數**：天數（例如 30）
- **隱藏小於 X KB 的圖片**：輸入 KB 數，0 或空白表示不隱藏

## 技術
- Kotlin + Jetpack Compose + Material 3
- Room（隱藏清單、垃圾桶、資料夾封面、LUX 預設、設定）
- DataStore（PIN 雜湊、鎖定狀態）
- MediaStore 讀取系統相片
- WorkManager 定期清理過期垃圾桶項目
- Coil 載入圖片（含 GIF）

## 建置
- 使用 Android Studio 開啟專案根目錄（含 `build.gradle.kts` 的資料夾）
- 同步 Gradle 後執行 Run 或 Build APK
- 若無 Launcher 圖示：可於 `res/drawable` 或 `res/mipmap-*` 加入自己的 `ic_launcher` 圖示

## 權限
- 讀取媒體（圖片 / 影片）
- 相機（若需在 app 內拍照）
- 儲存（若目標 API 需要）

## 注意
- 隱藏與垃圾桶為 app 內邏輯，實際檔案仍存在於儲存空間，僅在 app 中不顯示或移至垃圾桶清單
- 分享時 PIN 驗證通過後會呼叫系統分享；實際分享目標由使用者選擇
